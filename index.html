Sobre

Por que PulseIFData?

O IFData do BACEN é público, mas difícil de consumir: a API exige queries manuais por relatório e por trimestre, sem série histórica consolidada. O PulseIFData resolve isso — coleta, normaliza e entrega tudo em schema fixo, pronto para integração.

📦

Histórico consolidado desde 2000

Série completa de 25 anos em um único dataset. Sem iterar trimestre a trimestre na API do BACEN.

🔄

Schema normalizado e consistente

UTF-8, separador vírgula, decimal ponto, datas YYYY-MM-DD. O mesmo padrão dos outros produtos PulseDataLabs.

📊

Métricas derivadas inclusas

HHI de concentração, participação de mercado por IF, variação trimestral — o que o IFData bruto não entrega diretamente.

🔗

Integrável com o portfólio Pulse

Cruzamento nativo com PulseFlat (SELIC, CDI) para análises como NIM ajustado ao ciclo de juros.

Pipeline

Como funciona

Pipeline serverless que roda automaticamente após cada divulgação trimestral do BACEN — coleta, normaliza, enriquece e versiona os dados no repositório.

1

Detecção de nova divulgação

Monitor automático verifica a disponibilidade de novo trimestre no endpoint OData do IFData. Divulgações ocorrem ~60 dias após o fechamento do trimestre (março, junho, setembro) e ~90 dias para dezembro.

GitHub Actions · cron
2

Coleta via API OData do BACEN

Scrapers dedicados acessam o serviço IFDATA v1 do BACEN (Olinda), iterando sobre todos os relatórios disponíveis — cadastro de IFs, relatórios SCR (crédito) e Cosif (balanço/resultado).

olinda.bcb.gov.br · OData v4
3

Normalização e enriquecimento

Padronização de encoding, separadores e datas. Cálculo de métricas derivadas: participação de mercado por IF, HHI por segmento, variação QoQ e YoY, e mapeamento de segmento prudencial (S1–S5).

pandas · Python
4

Geração dos CSVs

Cada dataset é salvo em CSV plano (UTF-8, vírgula, ponto decimal). Séries históricas acumuladas — cada execução acrescenta o trimestre novo sem reescrever dados anteriores.

CSV · UTF-8 · imutável
5

Commit versionado no repositório

git add → git commit → git push. O CSV atualizado fica disponível imediatamente via URL raw do GitHub para consumo direto em Python, Excel, Power BI ou qualquer ETL.

Instalação

Comece em minutos

Clone, habilite o Actions e os dados chegam automaticamente a cada nova divulgação do BACEN.

1

Clone o repositório

Faça o fork ou clone direto do PulseIFData para sua conta GitHub.

2

Habilite o GitHub Actions

Na aba Actions do repositório, clique em Enable Actions. O pipeline já está configurado para monitorar novas divulgações do BACEN.

3

Rode manualmente para testar

Actions → Coleta IFData → Run workflow para verificar se a coleta e normalização funcionam antes da próxima divulgação trimestral.

4

Consuma os CSVs

Aponte seu Python, Excel ou ferramenta de BI para as URLs raw do GitHub. Os dados são versionados e imutáveis — cada trimestre fica registrado permanentemente.

5

Instale dependências Python (opcional)

Para rodar os scrapers localmente: pip install -r requirements.txt. Sem dependências proprietárias — apenas pandas, requests e aiohttp.

terminal 
# 1. Clone o repositório
git clone https://github.com/PulseDataLabs/PulseIFData.git
cd PulseIFData

# 2. Instale as dependências
pip install -r requirements.txt

# 3. Teste localmente — coleta todos os relatórios do trimestre mais recente
python run_all.py

# Ou um relatório específico
python run_all.py --relatorio credito_modalidade
python run_all.py --relatorio balanco_cosif

# 4. URL raw para importar direto no Python ou BI:
url = "https://raw.githubusercontent.com/PulseDataLabs/"
      "PulseIFData/main/data/credito_modalidade.csv"
